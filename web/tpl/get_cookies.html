QD Cookies 获取助手

在已登录的目标站点页面上一键导出 cookie 并发送给 QD，省去手动复制粘贴。 本仓库提供两条路线，选其一即可。

当前页面状态

扩展已安装并就绪：未检测到

如果你刚装好扩展并刷新过本页面，状态应显示「已就绪」。

方式 A：浏览器扩展（推荐，可拿 HttpOnly cookie）

  1. 下载扩展 zip（任选其一）：
    • 从当前 QD 实例下载 （即时打包自当前部署的 web/extension/get-cookies/，与你跑的代码完全同步）
    • 从 GitHub Release 下载 （字节确定性构建，附 sha256 校验，建议生产用户用这个）
  2. 解压后，打开 Chromium 系浏览器的扩展页（Chrome：chrome://extensions/，Edge：edge://extensions/），开启 开发者模式。
  3. 点 加载已解压的扩展程序，选择刚解压的目录。
  4. 装好后点扩展图标 → 选项，在白名单里加入当前 QD 站点（示例已自动填入）： 
    {{ '' }}
  5. 登录目标签到站点（不是 QD 站点）后，回到 QD 任务/HAR 编辑器点 获取 即可。

方式 B：Bookmarklet（零安装，仅可见 cookie）

把下面这个按钮 拖到浏览器书签栏，登录目标站点后点击它， cookie 会被复制到剪贴板，你再回 QD 粘贴即可。

📋 QD 复制 Cookie

⚠️ Bookmarklet 受 document.cookie 限制，拿不到 HttpOnly cookie （很多签到站的 session cookie 都是 HttpOnly，此时只能用方式 A）。
