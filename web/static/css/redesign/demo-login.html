QD 框架

基于 HAR 编辑器与 Tornado Server 的 HTTP 请求定时任务自动执行框架。 让繁琐的每日签到变得全自动。

  • ⏱
    定时自动执行 精确到分钟级的 cron 调度，无需手动操作
  • 🔄
    HAR 录制重放 录制浏览器请求，一键转换为可重复执行的任务模板
  • 📊
    执行日志追踪 完整的成功 / 失败记录，随时查看历史执行详情
  • 🔔
    多渠道推送通知 任务失败时通过 Telegram、微信等即时通知
